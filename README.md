## 👨‍💻 About Me

Hi, I'm an Informatics student at Telkom University Surabaya, currently in my 3rd semester. I'm especially drawn to artificial intelligence, cybersecurity, and penetration testing, and I enjoy exploring how intelligent systems work as much as how they can be broken and secured.

Right now, I'm working on personal projects that combine AI and security, building hands-on experience alongside my coursework.
I'm currently learning Machine Learning and Python for AI, along with network security, web application pentesting (OWASP Top 10), Linux, and sharpening my skills through CTF challenges on TryHackMe and Hack The Box.

I'm open to collaborating on AI/ML projects, security tools, and CTF teams, and I'm looking for help with building solid fundamentals in pentesting methodology and machine learning. Feel free to ask me about AI, cybersecurity, pentesting, or life as an Informatics student.
